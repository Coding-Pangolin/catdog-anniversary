# 猫狗的一周年

以原创猫狗角色、真实旅行合照和生活片刻为主角的周年互动手账。

- 普通入口：https://coding-pangolin.github.io/catdog-anniversary/
- 16:9 投影入口：https://coding-pangolin.github.io/catdog-anniversary/?view=projector

目前接入 10 个城市分组、12 页城市记忆、61 张精选照片，并复用于周年贺卡和回忆卡；另有 4 张大家庭原图，扭蛋机共 8 张回忆卡。杭州按不同照片月份分开记录；湖州&宁波沿用素材的混合分组。月份来自照片时间，实际行程可后续调整。昵称为猫猫和狗狗，在一起的日期为 2025.11.10；信件正文仍待补充。

首页提供浏览器端纪念暗号入口及遥控器数字键盘。它是体验入口，不是服务端鉴权；当前仓库和网站公开。完整访问保护后续接入。

## 本地开发

使用 Node.js 24 和 pnpm 11.25.0：

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build --base=/catdog-anniversary/
```

提交至 main 后，GitHub Actions 自动检查、构建并发布 GitHub Pages。网页资源支持项目子目录。

## 内容与使用

内容位于 `src/content.ts` 与 `src/travel-data.ts`。发布图片在 `public/photos/`，包含缩略图和大图，保留照片比例并移除 EXIF/XMP。原始照片和本地来源清单不上传仓库。

手机采用纵向旅行列表；桌面与 16:9 投影入口每屏显示三页记忆，可翻页访问全部内容。相册支持放大、照片切换、上一页和下一页城市记忆。投影模式支持方向键选择和确认键操作；Vidda 实际遥控器映射仍需真机复查。

《几分之几》使用 96 kbps 网页副本，完整缓存后播放。浏览器拦截自动播放时，第一次点击或确认后开始。影片放映期间（包括暂停）背景音乐暂停，影片结束或离开章节后恢复。投影模式减少持续动画与纹理绘制。

插画、照片、影片和音乐仅用于本次个人纪念项目；公开此仓库不代表授予再分发许可。

网站背景音乐已改为提供的《几分之几》（卢广仲）网页副本；影片文件及其中原有配乐保持原样。

## 我们的大家庭

猫猫、狗狗与四位毛绒家人：胖达（黑白狗）、枕头狗（抱着独立小枕头的棕色狗）、喵喵（大黄狗）、布拉肠（腊肠狗）。家庭成员配置在 `src/family-data.ts`，原图及缩略图索引在 `src/family-photos.ts`。头像由网页定位显示，原始画面可完整放大浏览；不自动编造加入日期。

大家庭入口贯穿封面、周年贺卡、旅行护照、相伴邮路和结尾信件。原影片仍保留此前的画面与原配乐。

## 最后填写信件

只需补充 `src/content.ts` 的 `letter`：称呼、正文段落、署名及落款日期，完成后将 `placeholder` 改为 `false`。手机正常阅读，投影模式自动分段分页。

已完成 31 项单元测试及浏览器全流程检查，涵盖三种手机宽度、桌面与投影尺寸、八章路径、抽卡不重复、旧进度兼容、礼盒刷新与结尾一致、十二页旅行、家人详情和原图、静音与视频互斥。Vidda/微信/iOS 的实体设备效果仍以真机测试为准。
